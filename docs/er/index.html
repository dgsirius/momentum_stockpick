🔥 热门资产跟踪+趋势资产判断

查看完整规则双门槛入池 · 趋势机会分 · 入场风险过滤
规则按“入池 → 描述 → 评分 → 候选”四步运行：热度决定关注池，核心趋势与 ER 衡量动能共振，入场质量控制位置风险，最终统一为“趋势机会分”。

1. 入池与退出

  • 只含美股单股，每次刷新同时满足 OpenD 综合热度 ≥ 1、总市值 ≥ 50 亿美元才入池。
  • 之后任一门槛失守，转为“保留观察”；从最后一次双门槛达标起，连续 50 个美股交易日未再达标才移出。
  • 期间重新达标，保留计数归零；若不再属于美股单股则直接移出。

2. 数据与刷新

  • 页面展示最近一次成功快照；本机手动刷新会同时更新热度、行情与 ER 榜单。
  • 热度图保留最近 30 个热度日；同日重复刷新只保留最新值。
  • 盘中使用未完成日 K/周 K；收盘使用最近完整周期。盘中量比与前 5 个周期的相同 15 分钟进度比较，避免把半日量和全天量直接相比。
  • 日线或周线历史少于 65 根时只显示“计算中”，不影响股票池资格。

3. 表格技术标签只负责解释

  • MA：5项均线顺序与收盘位置；MACD：零轴、DIF/DEA与柱体方向。
  • RSI：50–70健康强势，≥80过热，<40偏弱；Volume：当前量与前5个可比周期均量之比。
  • 这些标签便于快速读盘，悬停可看事实明细；它们不会再整套重复加入趋势机会分。

4. 趋势机会分

  • 核心趋势 75%：多周期波动调整动量40%、MA20/MA60斜率25%、趋势平滑度20%、相对 SPY/行业强度15%。
  • ER 15%：当前 Top10 名次60%、近5个榜单日命中25%、与4/12/36周价格动量同向15%。连续命中天数只展示，不重复计分。
  • 入场质量 10%：只修正当前位置，不替代趋势方向。
  • 融合原始分再转成当前双门槛达标标的中的 0–100 分位排名；保留观察标的仍显示分数，但不占用候选名额。分数表示相对优先级，不是上涨概率。

5. 入场质量与历史模型

  • 突破或回踩转强只算一次触发；MA20距离适中、RSI健康可加分。
  • 距离 MA20 超过 2.5 ATR、RSI≥80、向上跳空>5%、ATR%>6%或近20日回撤>10%会扣分。A为触发明确且无风险项，B为顺势观察，C不进入候选。
  • 历史延续模型的目标是未来40个交易日先到 +8%、且此前未到 −5%。只有样本外 AUC>0.55 才开始从核心趋势中取得权重，AUC≤0.55时权重为0，AUC≥0.60时上限20%。

6. 候选与排序

  • 候选只需同时满足三条：当前双门槛达标、趋势机会分 ≥95、入场质量 A/B。
  • 95分约等于当前股票池前5%，用于聚焦已经形成的成熟趋势；急反弹但尚不平滑的标的仍保留在全表。
  • 默认先排候选，候选之间按当前综合热度降序；点击“综合热度”可切换全表纯热度排序。顶部市场环境仅作背景，不参与评分或候选门槛。
历史大样本未证明95分比90分具有更高胜率，因此95分是筛选强度标准，不是收益或胜率承诺。盘中结果会随未完成 K 线变化。
